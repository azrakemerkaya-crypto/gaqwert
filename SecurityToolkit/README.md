# Security Toolkit

Bu klasör, `BordoStock` projesinden tamamen bağımsız tek sayfalık bir web projesidir.

## Çalıştırma

`SecurityToolkit/index.html` dosyasını tarayıcıda açmanız yeterlidir. Ek sunucu veya .NET kurulumu gerekmez.

## İçerik

- `index.html`: Arayüz
- `style.css`: Tasarım ve mobil uyumluluk
- `script.js`: SHA-256, format doğrulama, işlem günlüğü ve `.txt` indirme
