# Hazine Avı

Basit bir C# konsol oyunudur. Oyuncu 5x5 haritada hareket ederek gizli hazineyi bulmaya çalışır.

## Çalıştırma

Bilgisayarında .NET 8 SDK yüklüyse proje klasöründe şu komutu çalıştır:

```bash
dotnet run
```

## Kontroller

- `W`: Yukarı
- `S`: Aşağı
- `A`: Sola
- `D`: Sağa
- `Q`: Oyundan çıkış
